# Ahmed & Nora — Wedding Invitation (دعوة فرح أحمد ونورا)

Static wedding invitation site. Live at https://ahmed-norawedding.vercel.app/

- `index.html` — the whole site (RTL Arabic, countdown, petals animation)
- `assets/` — images and fonts

Deployed on Vercel (project `ahmed-nora-wedding`). Pushes to `main` deploy automatically.
